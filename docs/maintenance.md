# Maintenance

## Monthly

- Review open GitHub issues.
- Check Dependabot updates for GitHub Actions.
- Smoke test with the current stable Anki release.
- Review AnkiWeb comments or support reports.

## Before Large Changes

- Update `docs/ai/REPO_CONTEXT.md` if architecture changes.
- Add or update docs for new workflows.
- Confirm AnkiWeb templates still describe the add-on accurately.

## For Future Add-ons

Use this repository as a template, then update:

- `src/<package>/manifest.json`
- `README.md`
- `ankiweb/templates/ankiweb-description.md`
- `docs/development/configuration.md`
- `docs/ai/REPO_CONTEXT.md`
