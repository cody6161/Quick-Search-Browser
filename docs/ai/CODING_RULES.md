# Coding Rules

- Keep runtime code readable and direct.
- Avoid broad refactors during bug fixes.
- Use type hints in tooling scripts when they improve clarity.
- Keep comments useful and sparse.
- Avoid adding external dependencies to the add-on runtime.
- Keep generated files out of version control unless they are templates or placeholders.
- Preserve Anki user data and never automate destructive changes to user profiles.
