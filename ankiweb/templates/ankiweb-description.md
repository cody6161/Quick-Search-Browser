# Quick Search Browser

Quick Search Browser adds compact browser filters under Anki's normal Browser search controls.

## Features

- Hide suspended cards by default, with a toggle to show them.
- Filter new cards.
- Filter recently added cards.
- Filter cards due in 1, 3, 7, 14, or 30 days.
- Filter cards studied in 1, 3, 7, 14, or 30 days.
- Filter cards by any flag or by specific flag numbers.

## Compatibility

Test with the current stable Anki release before uploading. If a release supports only certain Anki versions, state that clearly here before publishing.

## Configuration

The `recent_added_days` option controls the Recent Added filter window. Configure it from Anki's add-on configuration dialog.

## Support

Open an issue on GitHub with your Anki version, operating system, steps to reproduce, and any error text.
